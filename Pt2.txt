2. Interactive background video

- Provide a static background fallback if the video cannot load.

6. Interactive avatar

Add a prominent AI avatar alongside the hero content.

Prefer a genuine 3D character with a compatible GLB/GLTF model, head and eye controls, and an idle animation. Implement smooth cursor-follow head rotation, subtle gaze tracking, and natural return to neutral when the pointer stops.

Do not fake actual 3D articulation with a single flat image. If a real 3D model asset is not provided, create a clear placeholder component and document exactly where the model file should be placed.

The avatar must:

- Load asynchronously without blocking the hero.
- Follow the pointer smoothly and clamp rotations.
- Respect reduced-motion preferences.
- Support a static mobile fallback when necessary.
- Fade out as the user scrolls away from the hero.
- Never obscure navigation, project cards, or other page content.

Keep the 3D implementation isolated so it can be disabled without breaking the website.

7. Scroll animations

Use IntersectionObserver or an appropriate lightweight motion implementation to animate content as it enters the viewport.

Include:

- Staggered fade-up reveals.
- Heading and paragraph reveals.
- Gentle image parallax.
- Subtle project-card hover transitions.
- Scroll progress indicator.
- Smooth section navigation.
- Consistent transitions between separate routes.

Animations must not block scrolling, create layout shifts, or continually replay when users move slightly back and forth. Respect prefers-reduced-motion.
